# Code of Conduct

## Our standard

Be respectful, specific, and constructive. Disagreement about security or
design is expected; harassment, threats, discrimination, sexualized conduct,
doxxing, and sustained personal attacks are not acceptable.

Participants should:

- critique code and claims rather than people;
- protect private reports, credentials, and personal information;
- disclose conflicts of interest that affect a review;
- give others room to correct mistakes;
- avoid overstating the security of experimental software.

## Enforcement

Report conduct concerns privately through the repository owner's GitHub
profile. Maintainers may edit or remove contributions, restrict participation,
or ban accounts when needed to protect the project and its participants.
Reports will be handled as confidentially as practical. Retaliation against a
good-faith reporter is not acceptable.
